YatraVibe — India Travel Blueprint

HOW TO SHOW IT:
1. Open index.html on any PC/laptop browser.
2. For phones, copy the folder to a web host (GitHub Pages, Netlify, Vercel, etc.) and open the link.
3. On a supported mobile browser, use Add to Home Screen / Install.
4. The site is responsive for desktop, tablet and mobile widths.

IMPORTANT:
- Destination photographs are loaded from online image URLs, so internet is needed for the images.
- This is a frontend blueprint/demo; booking, payments, login and backend APIs are not real.
- The included service worker caches the core shell when hosted over HTTPS.
